# Plain-language word swaps

Rule of thumb: if a word has a one-syllable cousin that means the same thing, use the cousin.

| Instead of | Use |
|---|---|
| utilize, leverage | use |
| facilitate | help |
| enable | let |
| streamline | simplify |
| empower | let, give |
| commence | start |
| demonstrate, illustrate | show |
| individuals | people |
| robust | strong |
| comprises, encompasses | includes, has |
| prior to | before |
| subsequent to | after |
| in order to | to |
| due to the fact that | because |
| a number of | some, many |
| in the event that | if |
| pursuant to | under |
| herein, hereof, hereunder | here, in this |
| mutatis mutandis | with the necessary changes |
| notwithstanding anything to the contrary | even if other parts say differently |
| it is important to note that | delete; just say it |
| it's worth noting | delete; just say it |
| at the end of the day | delete |
| when it comes to | delete or say "for" |
| in today's world, in the age of | delete |
| going forward | delete |
| in terms of | delete or rewrite |
| with regard to | about |
| the reality is, the truth is | delete; just say it |

## Often-empty adverbs

just, literally, honestly, simply, actually, truly, fundamentally, importantly, crucially, inherently, inevitably. Cut them when they add nothing. Keep them when they carry real emphasis, uncertainty, contrast, or the writer's natural spoken rhythm.
