# Accommodation Request Letter Template and Checklist

Based on the structure of JAN's sample accommodation-request language (https://askjan.org/articles/Sample-Language-for-Accommodation-Request-Letters.cfm). Adapt — do not send a generic letter.

## The template

Fill in the brackets. Keep it to one page. The user reviews and approves every word before anything is sent.

---

[Date]

[Supervisor or HR contact name]
[Company name]
[Address]

Dear [Name]:

I am writing to request a reasonable accommodation for [a disability / a medical condition — use only the level of detail the user approves].

Because of [the limitation — describe what gets in the way, not the diagnosis], I have difficulty with [the specific task, situation, or environment].

The accommodation I am requesting is [the specific change — for example: "unscheduled restroom breaks as needed," "a workstation closer to the restroom," "written instructions for new tasks"].

[Optional: one sentence on how the accommodation helps: "This will let me [do the task / stay on schedule / avoid missed time] without changing the work itself."]

I am happy to provide documentation from my health-care provider if needed, and to discuss alternatives that would work for both of us.

Thank you for your time.

Sincerely,
[Name]
[Contact information]

---

## What to include — and what to leave out

- **Include:** the limitation (what is hard), the specific accommodation being asked for, and willingness to discuss alternatives.
- **Leave out:** the full diagnosis, medical history, treatment details, and anything the user is not comfortable sharing. The letter does not have to name the condition at all.
- **Medical letter (separate document):** the provider states the disability, the limitation, and why the accommodation helps. Nothing more.

## Before sending checklist

1. The request describes a limitation, not a full medical file.
2. The accommodation is specific and practical.
3. The letter names who to reply to and how.
4. The user has a saved copy with the date it was sent.
5. If sending by email, the user keeps the sent email. If handing over paper, the user keeps a dated copy and notes who received it.
6. The user has a plan for follow-up: if there is no reply in a reasonable time, ask in writing for a meeting to discuss it.

## If the employer asks questions

- They may ask for documentation **only** if the disability or the need is not obvious — and only enough to confirm the disability and that it requires the accommodation.
- They may suggest a different accommodation. That is part of the interactive process. The user can accept it, counter it, or ask JAN for other ideas: (800) 526-7234.
- They must keep medical information **separate from personnel files**. Coworkers are not told.
- A "no" is not the end. The user can ask what the specific problem is, suggest an alternative, or contact JAN or a local disability-rights organization. Do not try to settle a legal dispute yourself — point to JAN, the EEOC, or a disability-rights attorney.

## Record-keeping log

Suggest the user keep a simple dated log:

| Date | What happened | Who | Notes |
|---|---|---|---|
| | Request sent | | Copy saved |
| | Employer reply | | |
| | Documentation shared | | What was shared, with whom |
| | Accommodation started | | |

The same log works for SSA wage reporting: date reported, method (app / phone / online / in person), pay stubs saved, receipt from SSA saved.
